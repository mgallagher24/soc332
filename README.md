Collecting data on all  2025-26 Division 1 basketball coaches, 2026-27 NBA coaches, and 2026 WNBA coaches.
Head Coach data is from Basketball-Reference.
NBA Assistant coach data is from [NBACoaches.com]([url](https://nbacoaches.com/nba-assistant-coaches/)). This assistant coach data is not updated for the 2026-27 season, but only those promoted to head coaching roles are omitted.
